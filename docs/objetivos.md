# Objetivos

## Objetivo de esta base

Disponer de reglas persistentes, documentación mínima y un destino GitHub autorizado para que cada proyecto pueda evolucionar sin duplicar archivos, perder contexto ni publicar secretos.

## Criterios

- Un repositorio por proyecto, adaptando las carpetas a la estructura real.
- `AGENTS.md` conserva las reglas de trabajo y los límites de autorización.
- Estado, decisiones y pendientes se actualizan al realizar cambios relevantes.
- Las verificaciones se describen con resultados reales, incluidos los bloqueos.
- Guardar localmente, sincronizar y desplegar son acciones distintas.
- No se modifica código ni documentación ajena para imponer esta estructura.

## Fuera del alcance inicial

- Crear una aplicación o elegir una tecnología sin requisitos.
- Copiar automáticamente otros proyectos o archivos de Windows.
- Instalar herramientas, cambiar otros repositorios o configurar despliegues.
- Asegurar que el repositorio es privado sin comprobar su visibilidad.
