# Pruebas automáticas

Este directorio está reservado. No hay pruebas automáticas configuradas ni un framework seleccionado.

Cuando se incorpore una aplicación, utiliza las pruebas y convenciones existentes o añade las adecuadas al proyecto real. Documenta el comando y su resultado en el `README.md` raíz y en `docs/estado.md`.

No presentes la existencia de esta carpeta como una prueba superada.
